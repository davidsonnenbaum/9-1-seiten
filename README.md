# 9-1.at · Seiten

Die Inhalte der Seiten von [9-1.at](https://9-1.at). WordPress lädt sie über `lader.js` von GitHub Pages.
Eine Änderung hier ist nach wenigen Minuten auf 9-1.at sichtbar, in WordPress muss nichts kopiert werden.

| Datei | WordPress-Seite |
|---|---|
| `seiten/startseite.html` | Startseite |
| `seiten/anliegen.html` | /anliegen |
| `seiten/karte.html` | /karte |
| `seiten/geschichten.html` | /geschichten |
| `seiten/faq.html` | /faq (Wer wir sind & FAQ) |
| `seiten/leitfaeden.html` | /leitfaeden (Leitfäden, z. B. Moderations-Guide) |
| `seiten/impressum.html` | /impressum |
| `seiten/datenschutz.html` | /datenschutz |
| `seiten/verhaltensregeln.html` | /verhaltensregeln |

Die Blöcke, die in WordPress stehen, sind in `wordpress-bloecke.md`.

Die Navigation oben auf jeder Seite kommt aus `lader.js` (Liste `MENUE`).
„Geschichten“ erscheint in Menü und Fußzeilen erst, wenn mindestens 2 Geschichten freigegeben sind (`GESCHICHTEN_AB` in `lader.js`). Die Seite /geschichten selbst bleibt immer erreichbar (Links „Deine Geschichte“ aus den Mails).
Dateien zum Herunterladen (z. B. `moderations-guide.pdf`) liegen in `downloads/`.
